# tracefast

The official Rust SDK for the [TraceFast API](https://docs.tracefast.xyz/api):
Ethereum blocks, transactions, traces, tokens, contracts and what TraceFast
states about an address.

```rust
use tracefast::{AddressesTransactionsParams, Client};

async fn run() -> Result<(), Box<dyn std::error::Error>> {
    let client = Client::new(std::env::var("TRACEFAST_API_KEY")?)?;
    let proxy = client.contracts().proxy("0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48").await?;
    println!("{:?} {:?}", proxy.data, proxy.meta);

    let params = AddressesTransactionsParams::new().limit(50);
    let mut pages = client.addresses().transactions_pages("0xd8da6bf26964af9d7eed9e03e53415d37aa96045", &params);
    while let Some(page) = pages.next_page().await? {
        println!("{} transactions", page.data.transactions.len());
    }
    Ok(())
}
```

**The API key is for server-side code.** It travels only in the `x-api-key`
header, never in a URL, an error or `Debug` output, and the client never follows
a redirect. Do not ship it inside a program that runs on someone else's machine
or in a browser (WebAssembly included): this SDK does not support that.

Every method returns the whole `{ data, meta }` envelope. Errors are one type,
`tracefast::Error`: branch on `code()` and `reason()`, never on `message()`.
The behaviour all TraceFast SDKs share is in `SPEC.md` at the root of the
repository; the API reference is at <https://docs.tracefast.xyz/api>.

The code under `src/generated/` and `tests/generated/` is generated by
`codegen/emit-rust.mjs` from the API catalogue snapshot — do not edit it.
